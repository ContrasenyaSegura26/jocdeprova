LETTER WHEEL — C1 English review (modal verbs & noun suffixes)

How to use
1. Unzip the folder.
2. Double-click index.html to open it in any modern browser (Chrome, Edge, Firefox, Safari).
   It also works uploaded to any website, Google Sites, Moodle, etc.

Files
- index.html    The page
- styles.css    Colours, fonts and layout
- script.js     Game rules (timer, score, pass, results)
- questions.js  The 26 clues — edit this file to change sentences or answers
- images/       Icon

Note: the fonts load from Google Fonts when online; offline the game still works with standard fonts.
